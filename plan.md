# ZeroFy Website Plan

## Project goals
- Build a minimal, user-friendly website for ZeroFy.
- Support website development, deployment, and maintenance services.
- Keep content simple, easy to read, and easy to navigate.
- Ensure the site works well on laptop, tablet, and mobile.
- Optimize basic SEO with clear page titles, descriptions, headings, and fast page loads.

## Pages
1. Home Page (`index.html`)
   - Hero section with value proposition and quick actions.
   - Services overview.
   - Quick links to important pages.
2. About Us (`about.html`)
   - Company mission and vision.
   - Simple process explanation.
3. Contact Us (`contact.html`)
   - Contact form.
   - Email and location details.
4. Blog Post List (`zlog.html`)
   - List of articles with short summaries.
5. Single Blog Post (`zlog-post.html`)
   - Full article layout with headings and easy scanning.
6. Forum Page (`zorum.html`)
   - Community discussion and topic summaries for website builders.

## UX recommendations
- Use simple labels: Home, About, Zlog, Contact.
- Keep paragraphs short and use headings to guide readers.
- Use a highlight color for actions and navigation.
- Make buttons and links large enough for mobile taps.
- Use whitespace to separate content and reduce visual clutter.

## Visual style and branding
- Font: `Inter` for a clean, modern feel.
- Primary color: Blue (`#1d4ed8`) for trust and clarity.
- Background: Light gray/white for a minimal, airy look.
- Accent: Soft blue on cards and buttons.
- Typography: Strong hierarchy with clear headings and body text.

## Technical structure
- HTML files for each page.
- Shared CSS in `css/styles.css`.
- Small JS in `js/script.js` for responsive menu behavior.
- Relative links for GitHub Pages compatibility.
- Use `index.html` as the landing page.

## GitHub Pages setup
1. Create a GitHub repository named `zerofy`.
2. Push the project files to the repository.
3. In repository settings, enable Pages from the `main` or `master` branch.
4. Use the default root folder for deployment.
5. Use `https://<username>.github.io/zerofy` or configure `zerofy.me` if DNS is available.

## Next steps

3. Replace placeholder email and mission details with your own.

## Suggestions
- Keep language direct and friendly.
- Explain services in plain words, not technical jargon.
- Show one clear action per page: contact, learn more, or read a post.
- Prioritize fast load times by keeping assets minimal.
- Consider adding a logo later, but start with strong text branding.
